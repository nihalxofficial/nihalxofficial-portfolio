## 🚀 Common Tasks

### **Update Your Bio:**
```
/control-centre/sections/about
→ Edit paragraphs, code card, highlights
→ Save Changes
```

### **Add a Project:**
```
/control-centre/sections/projects
→ Add New Project
→ Fill details, upload images, add tech stack
→ Create Project
```

### **Publish Blog Post:**
```
/control-centre/sections/posts
→ Add New Post
→ Write content (reading time auto-calculates)
→ Toggle Published
→ Create Post
```

### **Change Colors:**
```
/control-centre/settings/theme
→ Select preset OR custom colors
→ View live preview
→ Save Theme Settings
```

### **Upload Logo:**
```
/control-centre/settings/branding
→ Choose variant (Primary/Dark/Light/Icon)
→ Upload image
→ Save Branding Assets
```

## 💡 Pro Tips
